# Canvaパネルの色照合

Canvaで作っている**1ケース1ページのパネル**（7周年展示用）について、
ページ上下の細いラインの色が、確定した**主要タグ**（割合がいちばん大きいタグ）の色と
合っているかを自動で照合する。ページ数が多く目視では追えないため。
作成: 2026-08-21。

## 使い方

```bash
# 1. Canva で 共有 > ダウンロード > PNG >「すべてのページ」を選び、ZIPを取得
# 2. ZIPをこのディレクトリに置いて展開（ページ順を保つためPythonで展開する）
.venv/bin/python - <<'PY'
import zipfile, pathlib
z = zipfile.ZipFile('canva_check/【7周年編集用】CALL4パネル.zip')
dest = pathlib.Path('canva_check/pages'); dest.mkdir(parents=True, exist_ok=True)
for i, n in enumerate(z.namelist(), start=1):
    (dest / f"page-{i:03d}.png").write_bytes(z.read(n))
PY
# 3. 照合
.venv/bin/python canva_check/check_colors.py
```

PNGを使うのは**無圧縮で色が正確に取れる**ため。JPEGだと圧縮で色がにじみ、
隣接するタグ色との判別が甘くなる。

`unzip` を使わないのは、日本語のファイル名で書き込みエラーになるため
（Canvaは題名の無いページに設計名を付けるので、日本語名のファイルが混ざる）。
**ZIP内の並び順がCanvaのページ順**なので、順序を保って連番に振り直している
（番号名のファイルが全て正しい位置に来ることで確認済み）。

## 出力

`out/report.tsv` … 1ページ1行。Excelで開ける。
`out/page_map.json` … 連番 ↔ Canvaの元ファイル名の対応。

## 仕組み

1. ページ中央の最頻色を**地色**とみなす
2. 上端・下端から走査して、地色と違う帯（ライン）を探す
3. 11タグの配色と **OKLab距離**（ΔE×100）で照合。2〜3以下でほぼ同色
4. 主要タグは `tag_ratio/out/soft_tags_final.json` の確定値から取る
5. ページとケースの対応は**ページ内のQRコード**（CALL4のケースURL）から取る

### 帯の見つけ方（誤検出を2回踏んで直した）

条件を2つ課している。片方だけでは誤検出した。

- **端から8px以内に始まること** — これが無いと、ページ下部の白い吹き出し
  （原告コメントのボックス）を拾う
- **太さが4px以上あること** — これが無いと、最下部に1〜2pxの白い縁が入る
  ページ（`page-031`）でその縁を拾う

条件を満たす帯が複数あれば太い方を採る。実際のラインは19px前後。

### QRの読み方

等倍で読めないページがあるので、**3倍まで拡大し、グレースケール化と大津の2値化**も
試す（`page-004` は3倍で初めて読めた）。`opencv-python-headless` が必要:

```bash
.venv/bin/pip install opencv-python-headless
```

opencvが無い場合は `--by-order` でファイル名順をNo順とみなすが、
Canvaのページ順とNo順は一致していないので**推奨しない**。

### 配色の自動判定

Canvaがどの配色を使っているか分からないので、心当たりのある3つ
（カード・GUIの濃色／GUIの淡色／確認シートのチップ色）を全部試し、
観測した色との中央値ΔEが最小のものを採用して根拠も表示する。
`--palette` で固定もできる。

## 2026-08-21 の照合結果

92ページ（表紙1＋ケース91）。配色は**カード・GUIの濃色**で、
中央値ΔE=0.00（11ページだけΔE 1〜2.4）＝**Canvaと版下は同じ色を使っている**。

| | |
|---|---|
| 一致 | 90ページ |
| 不一致 | **1ページ**（`page-075` I0000149 オープンコート訴訟） |
| 上下の色が食い違う | なし |
| 88件すべてのケースが揃っている | ✓ |

**同じケースが2ページあるもの3件** — `I0000063`／`I0000052`／`I0000053`。
画素を比べると内容が違うので、同じケースの別バージョン（差し替え候補）と思われる。
どちらを使うかは人の判断。

### 唯一の不一致について

`I0000149` オープンコート訴訟は、Canvaが `政治参加・表現の自由`、
確定データは `公正な手続` 55% / `政治参加・表現の自由` 45%。

これは**フェーズ1で「未決着」と記録された12件のうちの1つ**で、確認者のメモは
「表現><手続 わかんない...」。フェーズ2でも順番を変更していないため、
計算値のまま（手続が僅差で上）になっている。

つまり**機械の僅差の判定と、Canvaの制作時の判断が食い違っている**状態で、
どちらかが間違いというより**人が決めていない**のが実態。
55:45の僅差なので、Canvaに合わせて `政治参加・表現の自由` を主役にするなら、
`tag_ratio` の確認シートで順番を入れ替えれば紙のマップ側も揃う。
